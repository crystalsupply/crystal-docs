# What is CrystalSupply?

CrystalSupply is a decentralized mining protocol built on the Monad blockchain that allows users to mine Crystal (TAL) tokens through a fair, transparent, and gamified system.

## Overview

Traditional cryptocurrency mining requires expensive hardware and consumes massive amounts of energy. CrystalSupply reimagines mining for the modern blockchain era by creating a **fair, accessible, and sustainable** alternative.

### Key Innovations

1. **Grid-Based Mining System**: Instead of computational power, miners stake MON tokens on a 25-block grid
2. **Provable Randomness**: Uses Pyth Entropy V2 for verifiable random number generation
3. **Auto-Compounding Staking**: Stake your mined TAL to earn protocol fees automatically
4. **Bitcoin-Inspired Halving**: Rewards halve every 3M TAL minted, creating scarcity

## How It Works (Simple Version)

```
1. Connect your wallet with MON tokens
2. Choose blocks on the 25-block grid to stake on
3. Wait for the round to end (~60 seconds)
4. Pyth Entropy randomly selects a winning block
5. Winners share TAL rewards proportionally
6. Stake TAL to earn auto-compounding protocol fees
```

## The Crystal (TAL) Token

Crystal (TAL) is the native token of the CrystalSupply protocol:

- **Symbol**: TAL
- **Max Supply**: 21,000,000 TAL
- **Decimals**: 18
- **Blockchain**: Monad
- **Purpose**: Governance, staking rewards, and value accrual

### Supply Distribution

Unlike many projects, CrystalSupply has **NO pre-mine, NO team allocation, and NO investor rounds**. Every single TAL token must be mined by the community.

| Component | Amount | Percentage |
|-----------|--------|------------|
| Minable Supply | 21,000,000 TAL | 100% |
| Pre-mine | 0 TAL | 0% |
| Team Allocation | 0 TAL | 0% |
| Initial Circulating | 105,000 TAL | 0.5% |

*Note: The 105,000 initial circulating supply is used to bootstrap liquidity and will be mined into existence at protocol launch.*

## What Makes It Fair?

### Provable Randomness

Every round's winning block is determined by **Pyth Entropy V2**, a decentralized random number generator that:

- Cannot be manipulated or predicted
- Is cryptographically verifiable
- Runs on-chain with transparent results
- Ensures every participant has a fair chance

### No Pre-mine

**100% of TAL supply must be mined**. The team, early supporters, and developers all must mine TAL like everyone else.

### Open Source

All smart contracts are open source and auditable. You can verify exactly how the protocol works before participating.
